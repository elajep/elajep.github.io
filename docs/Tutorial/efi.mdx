you will need a Window 10 installer flash drive. If you do not have this flash drive, you will have to build one. First download the 64-bit Windows 10 iso from this Microsoft web site. This can be done while running macOS. Next you will need 16 GB or larger flash drive.
Open a Windows Command Prompt window, by following the procedure outlined in this step. Below is an image of what is initially displayed by the Windows 10 installer. Select `Next` > `Use the old layout` > `Repair your computer` > `Troubleshoot` > `Command Prompt`.

Follow the given instruction:

Use the diskpart command to determine the drive letter for BOOTCAMP partition.

```bash
diskpart
list volume
exit
```

Enter the command below to assign drive letter `S` to the EFI partition.

```bash
mountvol S: /s
```

:::info note
Here I will assume the BOOTCAMP partition is assign the drive letter `C`. Enter the command shown below to recreate the boot files.

$$
a_0 + \sum_{n=1}^{\infty} a_n \cos{(nx)} + b_n \sin(nx)
$$

:::

```bash
bcdboot C:\windows /s S:
exit
```

$$
{\color{mediumvioletred}{a_0}} + \sum_{n=1}^{\infty}{\color{tomato}{a_n \cos(nx)}} + {\color{dodgerblue}{b_n \sin(nx)}}
$$

Notiamo come il termine $\color{mediumvioletred}{a_0}$ sia la media della $f(x)$,
se la funzione di partenza è dispari allora $\color{tomato}{a_n \cos(nx)}$ $= 0$,
se la funzione di partenza è pari allora $\color{dodgerblue}{b_n \sin(nx)}$ $= 0$
